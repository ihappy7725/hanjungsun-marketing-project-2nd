# 인플루언서 마케팅 — 한정선 베트남 크리에이터 협업 관리

> 한정선 찹쌀떡의 베트남 진출을 위해 현지 인플루언서 **발굴 → 검증·등록 → 협업 제안 → 회신·일정 정리 → 단가 기록 → 자료 반출**까지 한곳에서 처리하는 인플루언서 마케팅 탭의 기능 문서입니다.
>
> 담당: 진혁 · 문서 버전: **Ver_010** (2026-10-24) · 담당 폴더: `influencer_marketing/`
>
> 개인 브랜치(`Influencer`)에서 구현과 시험을 마쳤고, `premain` 머지 전입니다. 외부 API는 **가짜 응답(Mock) 시험**을 마쳤고, YouTube는 담당자 PC에서 실제 키로 검색·인기 순위 동작을 확인했습니다. 나머지 실제 환경 확인 항목은 11장에 있습니다.

## 먼저 읽기

- 이 문서는 최상위 `README.md`의 인플루언서 마케팅 범위를 구체화합니다. 공통 구조·데이터 소유권·Git 규칙은 최상위 README가 우선입니다.
- 대시보드 화면은 **한국어**, 인플루언서에게 보내는 메일은 **베트남어·영어·한국어(검토용)** 입니다.
- 협업 제안은 **메일 초안 생성과 복사까지**입니다. 자동 발송은 하지 않습니다.
- **외부 API 키가 하나도 없어도 기본 기능은 모두 동작합니다.** 키가 없는 서비스는 꺼져 있거나 접혀 있을 뿐입니다.
- 크롤링(사이트 화면 자동 수집), 비공식 로그인 자동화, 접근 제한 우회는 **하지 않습니다.** 공식 API와 사용자가 확인·보유한 자료만 씁니다.
- 가상 인물·견적은 모두 **시연 데이터**로 표시되며, 버튼 하나로 시연 데이터만 지울 수 있습니다.

## 2. 사용 흐름

### 2.1 기본 흐름

1. **[발굴]** 에서 후보를 찾습니다. 방법은 아래 중 편한 것을 씁니다.
   - YouTube 후보 검색 → 필요하면 [지표 채우기]
   - 인기 순위 (YouTube 베트남 인기 차트, 식품 관련만)
   - 후보 직접 입력 → [주소로 지표 채우기]
   - 파일로 여러 명 가져오기 (SaaS 내보내기·에이전시 자료 자동 정제)
2. 결과에서 출처·신뢰도·등록 여부를 보고 골라 **[선택한 후보 등록]** → "후보" 상태로 들어갑니다. 같은 계정은 자동으로 건너뜁니다.
3. **[제안 메일]** 에서 캠페인을 불러오고 메일을 확인·번역 대조한 뒤 복사해 보냅니다 → [제안 발송으로 표시].
4. **[회신 정리]** 에 받은 회신을 붙여 넣어 자동 정리 → 확인 후 저장.
5. **[일정]** 에서 촬영일 확정 → **[광고 단가]** 에 견적·계약가 기록 → **[내보내기]** 로 CSV·PDF.

### 2.2 API 키가 없을 때

[TikTok One 열기] · [검색 기준 복사] → 화면에서 본 숫자를 **후보 직접 입력**에 적거나 **발굴 후보 CSV 양식**에 채워 올립니다.

### 2.3 기념일 캠페인과 연결

HOME 캘린더에서 `/influencer_marketing/?event_id=...` 로 들어오면 그 기념일에 연결된 협업만 보이고, 이 상태에서 등록한 인플루언서는 기념일이 자동으로 연결됩니다.

## 3. 탭별 기능

### 3.1 요약

- 등록 인원·제안 발송·회신율·계약 확정 이상·확인 필요 회신, 진행 단계 막대, 대표 플랫폼·규모 분포, 14일 안의 일정
- **다음 할 일**: 회신 확인 → 회신 지연(7일) → 촬영일 확정 → 촬영 임박(14일) → 지표 갱신(45일 경과)
- 아무도 없을 때: **[발굴] 탭에서 자동으로 찾기** · 직접 입력해서 추가 · 시연 데이터 넣기

### 3.2 인플루언서

| 항목 | 기준 |
| --- | --- |
| 기본 정보 | 이름(필수), 대표 핸들, 분야(디저트·먹방, 맛집 리뷰, 라이프스타일, 가족·육아, K-컬처, 뷰티, 여행, 기타), 지역(호치민·하노이·다낭·기타), 이메일, Zalo, 매니지먼트 |
| 채널 지표 | TikTok·Facebook·YouTube·Instagram별 팔로워, **조회수 중앙값**, 채널 주소 (+ 평균 조회수·참여율·베트남 시청자 비중·출처·수집일·신뢰 수준) |
| 진행 상태 | 후보 → 제안 발송 → 회신 받음 → 협상 중 → 계약 확정 → 촬영 완료 → 게시 완료 / 불가·보류 |
| 자동 채우기 | 편집 창에서 채널 주소 입력 → [YouTube 지표 가져오기] (구독자·조회수 중앙값, 약 3유닛) / [Phyllo로 가져오기] (권한이 있을 때) |

- **조회수는 평균이 아닌 중앙값**(최근 영상 기준)을 씁니다. 평균만 아는 값은 "평균 조회수" 칸에 따로 저장합니다.
- 규모 등급: Nano 1천~1만 / Micro 1만~5만 / Mid 5만~10만 / Macro 10만~50만 / Mega 50만 이상
- 지표가 바뀔 때마다 **지표 기록**이 쌓여 편집 창에서 시점별로 비교할 수 있습니다.

### 3.3 발굴

**① 조건 검색** — 플랫폼, 국가(베트남), 콘텐츠 언어, 팔로워 최소·최대, 최소 조회수, 최소 참여율, 베트남 시청자 비중, 카테고리, YouTube 검색어(베트남어 검색어 예시 14개 버튼 — 한국어 뜻 표시, 누르면 입력)

| 조건 | YouTube | Modash | HypeAuditor |
| --- | --- | --- | --- |
| 팔로워 | 결과에서 거름 | 지원 | 지원 |
| 조회수·참여율 | 검색 단계에선 없음 → **[지표 채우기]** 로 가져옴 | 지원 | 지원 |
| 베트남 시청자 비중 | **공개 API로 알 수 없음** | 지원 | 지원 |

- 값을 주지 않는 조건은 **표 위에 한 줄로 안내**하고, 행은 빼지 않고 "–"로 표시합니다.
- **[지표 채우기]**: 결과(최대 25개)의 YouTube 채널은 최근 영상 15개로 조회수 중앙값과 **참여율((좋아요+댓글)÷조회수의 중앙값, 공식 API 값으로 계산한 추정치)** 을 채웁니다(채널당 약 3유닛). TikTok·Instagram은 Phyllo 권한이 있을 때 채웁니다. 채운 뒤 조건을 다시 적용하고, 빠진 인원·실패를 알려 줍니다.

**② 인기 순위 (공식 API)**

| 종류 | 집계 기준 | 비용 |
| --- | --- | --- |
| YouTube 베트남 인기 영상 | YouTube 공식 인기 차트(`chart=mostPopular`, 지역 VN) | 약 4~8유닛 |
| 인기 영상의 채널 (구독자 순) | 인기 차트에 오른 영상의 채널을 구독자로 재정렬 (베트남 전체 순위 아님) | 약 2~8유닛 |
| YouTube 키워드 채널 (구독자 순) | 키워드로 모은 베트남 채널 중 순위 (베트남 전체 순위 아님) | 50개당 약 101유닛 |
| Modash·HypeAuditor (팔로워 순) | 각 서비스 베트남 검색 결과 | 크레딧 차감, 키가 있을 때만 표시 |

- Top 30 / 50 / 100, **기준 시각을 한국(KST)·베트남(ICT) 시간으로 함께 표시**, 마지막 순위 저장, [순위 CSV 내려받기]
- **식품 관련만 보기(기본 켜짐)**: 인기 차트 200개에서 게임·음악·스포츠·뉴스를 빼고 제목·태그·설명에 음식 단어가 있는 영상만 남깁니다. "200개 중 n개"를 표시하고, 적으면 키워드 채널을 쓰라고 안내합니다.

**③ TikTok One 연계 (API 없음)** — [TikTok One 열기](`https://ads.tiktok.com/creative`, 광고주 로그인 필요), [크리에이터 검색 공식 안내], [검색 기준 복사]. TikTok One 크리에이터 검색 API는 일반 광고주 권한이 확인되지 않아 연결하지 않았습니다.

**④ 후보 직접 입력** — 계정 주소 입력 → **[주소로 지표 채우기]** (YouTube는 공식 API로 이름·구독자·조회수 중앙값·참여율, TikTok·Instagram은 Phyllo 권한이 있을 때. Facebook은 수동) → [중복 확인] → [후보로 등록]. 출처는 자동으로 "YouTube API"·"Phyllo"로 바뀌고, 직접 본 값은 "TikTok One 화면 확인·채널에서 직접 확인·인플루언서 제출·에이전시 자료" 중에서 고릅니다.

**⑤ 파일로 여러 명 가져오기 (자동 정제)** — CSV·TSV(5MB·2,000행)를 올리면 저장 전 미리보기로 보여 줍니다.

| 정제 | 처리 |
| --- | --- |
| 인코딩·구분자 | UTF-8, CP949(한국어 엑셀), UTF-16, CP1258 / 쉼표·탭·세미콜론 자동 판별 |
| 열 이름 | 한국어·영어·베트남어 열 이름 자동 대응, 성장률·사진 주소 열은 사용 안 함 |
| 숫자·비율·날짜 | `1.2M`, `12,5K`, `1.234.567`, `15 triệu`, `3만` / 0~1 비율 → % / `dd/mm/yyyy` → `YYYY-MM-DD`. 읽지 못한 값은 비우고 사유 표시 |
| 조회수 기준 | 중앙값 열만 중앙값 칸에, 기준 없는 `Views`는 평균 칸 + "조회수 기준 불명" 메모 |
| 중복·출처·시연 | 파일 안 중복 제외, 기존 계정 "등록됨", 파일 출처·제공처 선택, **"시연용 파일" 체크 시 시연 데이터로 등록** |

- 엑셀(.xlsx)은 'CSV UTF-8'로 저장해서 올립니다(대시보드에서 직접 읽지 않음).

**중복 기준** — 같은 플랫폼 + 같은 계정이면 중복입니다. 주소 형식·대소문자가 달라도 같은 계정으로 봅니다(`https://www.tiktok.com/@BanhNgon.VN?lang=vi` = `@banhngon.vn`). YouTube 채널 ID 주소와 핸들 주소는 같은 채널로 알아보지 못하니 같은 형식으로 저장합니다.

### 3.4 제안 메일

- 캠페인 정보(브랜드, 제품명 3개 언어, 회사명, 보내는 사람, 회신 이메일·Zalo, 기간, 회신 기한, 비용 문구, 광고 가이드라인)가 **메일 본문에 자동으로 들어갑니다.**
- **저장된 캠페인**: 캠페인 정보를 이름 붙여 저장(최대 30개)하고 [불러오기]로 꺼내 씁니다. 불러오면 칸과 메일에 바로 적용됩니다. 같은 이름은 한 번 더 눌러야 덮어쓰고, 삭제도 두 번 눌러야 합니다. 환율은 캠페인에 저장되지 않습니다.
- 메일 끝 **번호형 회신 양식**: ① 가능 여부 A/B/C ② 협의 가능일 ③ 촬영 가능일 ④ 게시 가능일 ⑤ 희망 비용(VND) ⑥ 기타
- 기본 광고 가이드라인에 베트남 개정 광고법(Law No. 75/2025/QH15, 2026-01-01 시행) 핵심 반영: 광고 표시, 직접 써 본 제품만 홍보, 식품 효능 표현 금지
- **번역해서 대조하기 (6방향)**: 한→베, 베→한, 영→베, 베→영, 한→영, 영→한 버튼을 누르면 **Google 번역이 새 창으로** 해당 언어 쌍과 글이 채워진 채 열립니다(무료·키 없음).
  - ① 미리보기 메일(제목+본문)을 번역 ② 번역 결과를 대조 칸에 붙여 넣고 반대 방향으로 다시 번역 → 원문과 비교
  - 5,000자가 넘으면 글을 복사하고 빈 번역 창을 엽니다. 기계 번역이라 발송 전 현지 검수를 권장합니다.

### 3.5 회신 정리

- 받은 메일·Zalo 메시지를 붙여 넣으면 가능 여부(A/B/C, có thể 등), **베트남식 날짜(dd/mm)**, 비용("15 triệu", "6,5 triệu")을 읽어 채웁니다. 헷갈리는 항목은 **"확인 필요"** 로 표시합니다.
- 오른쪽 **받은 회신**의 [열기]를 누르면 왼쪽 입력칸에 불러오고, 해당 줄 강조·화면 이동·안내가 나옵니다.
- **수정**: 불러온 뒤 고쳐서 [회신 수정 저장]. **삭제**: [회신 삭제]를 두 번 누르면 회신이 지워지고 상태가 '제안 발송'(발송 기록이 없으면 '후보')으로 돌아갑니다. 계약 확정 이후 상태와 확정 촬영일·게시일은 그대로 둡니다.

### 3.6 일정

협의 가능일(점선), 촬영 가능일, **촬영 확정일(팥색)**, 게시 예정일을 한 달력에 표시합니다. 같은 날 촬영 확정이 2건 이상이면 빨간 테두리. 날짜 기준은 **베트남 시간(UTC+7)** 입니다.

## 12. 발표 시연 순서 (2026-10-28)

실제 인물이 아닌 **시연 데이터**로 진행하며, 1~6은 키 없이도 됩니다.

1. **[요약]** 시연 데이터 넣기 → 진행 단계·다음 할 일
2. **[발굴] 파일로 여러 명 가져오기** — 시연용 파일 체크 → 정제 결과(열 대응·`1.2M` 정리·비율 변환·중복) → 등록
3. **[발굴] 후보 직접 입력** — 등록 → 같은 계정 재등록 시 "이미 등록된 계정"
4. **[제안 메일]** — 저장된 캠페인 불러오기 → 베트남어 메일 → **[베→영] → 결과 붙여 넣기 → [영→베]** 로 번역 대조
5. **[회신 정리]** 회신 붙여 넣기 → 자동 정리 → (오입력 시) 수정·삭제 → **[일정]** 촬영일 확정
6. **[광고 단가]** 참고가 비교·출처 → 환율 직접 입력·저장일 → **[내보내기]** CSV·PDF
7. (YouTube 키) **[발굴] 인기 순위** 식품 관련만 Top 30 → 기준 시각 → 채널 등록 → 순위 CSV
8. (YouTube 키) **[발굴] 조건 검색** → 표 위 안내 → **[지표 채우기]** 로 조회수·참여율 채우고 조건 재적용
