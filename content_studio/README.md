# 콘텐츠 스튜디오

> 한정선 제품 정보와 베트남 현지 일정을 바탕으로 **포스터·카드뉴스·영상**을 대화로 만들고, 가운데 화면에서 바로 고치는 탭입니다.
> 

**문서 상태: 개발 중.** 화면과 흐름은 시연 데이터로 동작합니다. 이 문서는 지금 구현된 것과 앞으로 만들 것을 함께 적습니다.

| 표시 | 뜻 |
| --- | --- |
| ✅ | 구현됨 (시연 데이터·간이 방식 포함) |
| 🛠 | 구현돼 있지만 이 문서 기준으로 **바꿀 예정** |
| 📝 | 설계만 있음 (아직 구현 전) |

| 담당 | 맡은 영역 |
| --- | --- |
| 유진 (PM2) | **영상** 탭(Higgsfield), 탭 공통 기능(대화·이전 작업·되돌리기·화면 틀), 탭 공동 파일 |
| 희주 | **포스터** 탭(AI 포스터·Figma), **카드뉴스** 탭(템플릿·기본 프롬프트·Canva), **배경 제거**, 사진 업로드, 광고 표현 검수 |

## 1. 이 탭에서 하는 일

탭 위쪽의 작은 탭 세 개로 나뉩니다. 각 탭 안에서 처음부터 끝까지 한 화면에서 끝냅니다.

| 탭 | 하는 일 | 결과물 | 연동 | 담당 |
| --- | --- | --- | --- | --- |
| **포스터** | 목적·제품·문구·분위기·규격을 말하면 AI가 문구와 이미지를 만들고, 요소(레이어)별로 나눠 구성. 대화나 직접 수정으로 다듬기 | PNG/JPG, (검증 후) SVG·Figma | GPT(OpenAI), Figma | 희주 |
| **카드뉴스** | 받은 템플릿과 **기본 프롬프트**에 맞춰 인스타그램 게시글용 카드뉴스 생성·수정 | PNG 여러 장 (4:5·1:1) | GPT 또는 Canva | 희주 |
| **영상** | 요청대로 Higgsfield 프롬프트 초안을 짜고, **사용자 검토·승인 후** 영상 생성 | 영상(mp4) | Higgsfield | 유진 |

### 사용 흐름

```
① 탭 고르기 (포스터 / 카드뉴스 / 영상)
        ↓
② 첫 화면: 내 작업을 가로로 넘겨 보기 → 이어서 열기
          또는 아래 "지금 만들면 좋은 것"(기념일·제철·신메뉴 추천) 카드 누르기
          또는 "새로 만들기"
        ↓
③ 작업 화면: 가운데 결과물 + 오른쪽 대화 (+ 사진 첨부 → 눌러서 편집·배경 제거)
   ├─ 포스터·카드뉴스: 말로 고치기 / 가운데에서 직접 고치기 / ← → 되돌리기·다시하기 / 내보내기
   └─ 영상: ① 초안(장면 구성) → ② 프롬프트 검토·수정 → ③ "이 프롬프트로 영상 만들기" → 결과 재생
        ↓
④ 왼쪽 "이전 작업"에서 언제든 이어서 하기
```

## 3. 포스터 탭 (희주)

### 3-1. 목적

마케터가 디자이너 없이 대시보드에서 홍보 포스터를 만들고 고칩니다. 전문 편집이 필요하면 Figma로 넘겨 이어서 작업합니다.

### 3-2. 흐름

1. 마케터가 **제품명, 홍보 목적, 핵심 문구, 디자인 분위기, 규격**을 입력합니다.
2. AI가 포스터 문구와 배경·제품 연출 이미지를 만듭니다.
3. 제목·본문·배경·제품 이미지 등을 **서로 다른 편집 요소(레이어)**로 구성합니다.
4. 마케터는 대화로 수정을 요청합니다. 예: "제목을 크게", "사진을 오른쪽으로".
5. 결과를 확인하고 PNG/JPG로 내려받습니다.
6. Figma 연동이 검증되면, 편집 가능한 Figma 파일로 이어서 작업합니다.

> **핵심 원칙:** `JPG 생성 → SVG 변환`에 의존하지 않습니다. JPG/PNG는 픽셀이 합쳐진 이미지라서 SVG로 바꿔도 제목·사진·배경이 저절로 나뉘지 않습니다. **처음부터 요소를 나눠서 만들고 관리합니다.** 지금 편집기도 포스터를 요소별 JSON 문서(8장 형식)로 저장합니다.
> 

### 3-3. 기능별 상태

| 기능 | 상태 | 내용 |
| --- | --- | --- |
| 요소(레이어) 구조 | ✅ | 제목·부제·배지·브랜드·사진·도형·일러스트를 각각 독립 요소로 저장 |
| 규격 | ✅ | 1:1 · **4:5(기본)** · 9:16 · 16:9. 바꾸면 요소가 비율에 맞춰 옮겨집니다. |

| 작업 원본 저장·재편집 | ✅ | 요소 JSON을 버전별로 저장하고, 이전 작업에서 다시 엽니다. |
| SVG 내보내기 | 📝 | 검증 후 단계적으로 추가 (3-6) |

### 3-4. Figma 연동 방식

| 방식 | 구현 방향 | 한계 |
| --- | --- | --- |
| **A. AI 대화형 편집 + Figma 연동 (우선 검증)** | 대시보드의 요청을 AI가 해석하고, 지원되는 Figma 연동 경로(공식 Figma MCP 등)로 레이어를 만들고 고칩니다. | MCP 연동 가능 범위, 인증·권한, 비용, 수정 정확도 검증 필요 |
| B. 자체 편집기 + Figma 연동 | 대시보드에서 글·사진을 직접 눌러 옮기고, 필요할 때 Figma로 넘깁니다. | Figma 호환 내보내기 개발 필요. **자체 편집기는 이미 있으므로** Fabric.js 같은 캔버스 라이브러리는 꼭 필요할 때만 검토 |
| Figma 파일 임베드 | 대시보드에 Figma 파일의 보기·미리보기 표시 | **완전한 Figma 편집기를 대시보드 안에 넣는 것과 다릅니다.** |
- **1차 방향은 A안을 먼저 기술 검증**합니다. 실제 서비스 환경에서 제한되거나 쓰기 불편하면 B안으로 갑니다.
- MCP는 AI와 도구를 잇는 프로토콜입니다. Figma 편집 화면을 대시보드 안에 넣어 주는 기술이 아닙니다.
- Figma 공식 MCP의 지원 범위와 외부 웹 대시보드에서 쓸 수 있는지는 **도입 시점의 공식 문서·인증 방식·계정 권한·요금제**로 확인합니다. 이 문서는 연동 완료나 무제한 편집을 보장하지 않습니다.

### 3-5. 글꼴

| 종류 | 상태 | 내용 |
| --- | --- | --- |
| 무료 웹글꼴 44종 | ✅ | Google Fonts. 고딕 · 명조 · 제목·굵은 · 손글씨·귀여운 · **베트남어·영문**(Be Vietnam Pro·Montserrat 등). 처음 쓸 때만 불러옵니다. |
| 내 PC 글꼴 | ✅ | 글꼴 목록 맨 아래 "내 PC 글꼴 불러오기"를 누르고 권한을 허용하면, 그 PC에 설치된 글꼴(워드 글꼴 포함)을 씁니다. 크롬·엣지만 지원합니다. |
- 내 PC 글꼴은 그 PC에서만 보입니다. PNG로 받으면 그대로 들어갑니다.
- 워드 글꼴 파일을 서버에 올려 나눠 주지 않습니다. 이미지로 만들어 상업적으로 쓸 수 있는지는 글꼴마다 확인합니다.
- 베트남어 문구는 성조를 지원하는 "베트남어·영문" 묶음 글꼴을 권장합니다.

### 3-6. SVG 내보내기 가이드 (📝)

편집할 수 있는 SVG를 만들 때 지킬 것:

- 모든 문구는 아웃라인·패스가 아니라 **`<text>` 요소**로 유지합니다.
- 제목·부제목·본문·CTA를 각각 독립된 글 요소로 둡니다.
- 배경·제품 이미지·장식·글을 별도 그룹(레이어)으로 관리합니다.
- Figma·Illustrator에서 열어 글 수정과 요소 이동이 되는지 실제로 시험합니다.
- 글꼴이 설치되지 않은 곳에서는 글꼴이 바뀌고, 외부 이미지 참조가 빠질 수 있으니 내보내기 전에 검사합니다.
- SVG는 원본 작업 파일을 완전히 대신하지 못합니다. 다시 편집할 수 있도록 요소 JSON도 따로 저장합니다(지금 구조 그대로).

**할 수 없거나 보장할 수 없는 것**

- 포스터 전체를 JPG/PNG 한 장으로 만든 뒤 SVG로 바꿔 **모든 요소를 정확히 되살리기**
- SVG 안의 일반 사진을 모두 편집 가능한 벡터로 만들기
- 어떤 SVG든 Figma/Illustrator에서 원본과 **100% 같게 편집**하기
- Figma MCP만 연결해 **Figma 편집 화면 전체를 대시보드 안에 넣기**

## 4. 카드뉴스 탭 (희주)

인스타그램 게시글로 올릴 카드뉴스를 만듭니다.

### 4-1. 기능별 상태

| 기능 | 상태 | 내용 |
| --- | --- | --- |
| 임시 템플릿 4종 | ✅ | 깔끔 정보형 · 사진 강조형 · 체크리스트형 · 감성 문구형. **받을 실제 템플릿으로 바꿀 예정**입니다. |
| 템플릿 바꾸기 | ✅ | 첫 화면에서 고르거나, 작업 중 위쪽 목록이나 "체크리스트형으로 바꿔줘". 글·색·사진은 유지됩니다. |
| 구성 | ✅ | 3~6장. 1장은 표지, 나머지는 안쪽 장(쪽 번호·제목·본문) |
| 규격 | ✅ | **4:5(기본)·1:1**만 |
| 고치기·내보내기 | ✅ | 포스터와 같습니다. 장 번호 버튼으로 장을 옮기고, PNG는 장마다 따로 받습니다. |
| 실제 템플릿 | 📝 | 마케터가 템플릿 몇 개를 줍니다(4-2). |
| 기본 프롬프트 | 📝 | 모든 카드뉴스 생성에 항상 깔리는 기본 지침을 설정합니다(4-3). |
| 생성 방식 | 📝 | GPT 또는 Canva 중 정합니다(4-4). |

### 4-2. 템플릿 (📝)

- 마케터가 실제로 쓸 카드뉴스 템플릿을 몇 개 줍니다.
- 받은 템플릿은 다음 중 맞는 방식으로 등록합니다.
    - **우리 편집기 템플릿:** 요소 JSON(배치·글꼴·색)으로 옮겨 지금의 템플릿 4종을 대신합니다.
    - **Canva 브랜드 템플릿:** Canva에 올려 두고, 우리 글·사진을 채워 넣습니다.
- "학습"은 AI 모델을 새로 훈련하는 것이 아닙니다. **템플릿과 좋은 예시를 참고 자료로 AI 요청에 함께 넣어** 그 스타일을 따르게 하는 방식입니다.

### 4-3. 기본 프롬프트 (📝)

카드뉴스를 만들 때마다 **항상 먼저 들어가는 기본 지침**입니다. 마케터는 매번 같은 조건을 말하지 않아도 됩니다.

들어갈 내용 (예시, 실제 문구는 마케터가 정합니다):

- 베트남에서 **금기시하는 표현·색·상징**을 쓰지 않는다.
- 베트남 현지 **최신 유행**을 따른다.
- **성차별·인종차별** 등 차별적인 표현을 쓰지 않는다.
- **한국 브랜드(한정선)다운 색과 느낌**을 살린다.
- (그 밖에 브랜드 톤, 광고 표현 주의사항 등)

| 항목 | 설계 |
| --- | --- |
| 저장 위치 | 설정 파일(예: `content_studio/prompts/cardnews_base.md`) 또는 화면에서 고치는 설정 — 9장에서 결정 |
| 쓰는 곳 | 카드뉴스 생성·수정 요청을 AI(GPT·Canva)에 보낼 때 맨 앞에 붙입니다. |
| 사용자 요청과의 관계 | 기본 프롬프트 + 템플릿 참고 + 사용자 요청 순서로 보냅니다. 사용자 요청이 기본 지침과 충돌하면 기본 지침을 따릅니다. |
| 광고 표현 검수와의 관계 | 기본 프롬프트로 예방하고, 결과 문구는 광고 표현 검수(6장)로 한 번 더 확인합니다. |

### 4-4. 생성 방식 (📝)

| --- | --- | --- |
| GPT | 기본 프롬프트 + 템플릿 참고로 장별 문구·배치(요소 JSON)를 만들고, 우리 편집기에서 고칩니다. | 모델·비용, 결과 형식 안정성 |

## 5. 배경 제거 (희주)

제품 사진의 배경을 지우고 투명 배경 PNG로 받는 기능입니다. 포스터·숏폼·카드뉴스에 들어갈 **한정선 찹쌀떡 누끼 이미지**를 빠르게 만드는 것이 목적입니다.

### 5-1. 위치와 흐름 (✅ 화면은 구현됨)

별도 페이지를 두지 않고, **입력창에 사진을 첨부한 뒤 보내기 전에 그 사진을 누르면 열리는 사진 편집 창**에 둡니다. 세 탭이 같은 창을 씁니다.

1. 사진을 첨부합니다: 📎 버튼, 끌어다 놓기, Ctrl+V 붙여넣기
2. 첨부 사진을 누르면 사진 편집 창이 열립니다.
3. **배경 제거** 탭에서 버튼을 누르면, 처리하는 동안 로딩 표시를 보여줍니다.
4. 결과는 체크무늬(투명) 배경 위에 보여줍니다.
5. **배경 제거 이미지 받기**로 투명 PNG를 따로 받거나, **적용**해서 첨부 사진으로 씁니다.

같은 창에서 자르기(자유·1:1·4:5·9:16·16:9), 90° 회전, 좌우 반전, 밝기·대비·채도, 원본으로, 받기도 할 수 있습니다(✅).

### 5-2. 입력 조건 (🛠)

| 항목 | 기준 |
| --- | --- |
| 형식 | JPEG, PNG, WEBP |
| 용량 | 최대 15MB (지금은 10MB → 15MB로 변경) |
| 크기 | 가로·세로 각각 최대 4096px |
| 개수 | 한 번에 1장 |
- 같은 조건을 **화면(JS)과 서버(Python) 양쪽**에서 검사합니다. 화면 검사는 편의용이고, 최종 판단은 서버가 합니다.
- 서버는 확장자만 보지 않고 Pillow로 실제 이미지를 열어 형식과 크기를 확인합니다.
- 15MB 제한은 Flask 설정 `MAX_CONTENT_LENGTH`로 막습니다. 앱 전체 설정이라 PM1 상준에게 요청합니다.

### 5-3. 구현 방식 — AI 모델·외부 API 없이 직접 구현 (🛠)

학습된 AI 모델이나 외부 API를 쓰지 않고, **이미지 처리 알고리즘을 직접 조합해** 배경을 지웁니다. API 키가 필요 없습니다.

> 지금 코드는 임시입니다. Pillow로 네 모서리 색을 채워 지우는 간이 방식이고, remove.bg 연동 코드도 들어 있습니다. **아래 방식으로 바꾸고 remove.bg 코드는 뺍니다.**
> 

| 구분 | 선택 | 사용 목적 |
| --- | --- | --- |
| 배경 분리 | `opencv-python-headless` | 색 거리 계산, GrabCut, 모폴로지 연산 |
| 배열 계산 | `numpy` | 픽셀 단위 마스크 계산 |
| 이미지 입출력 | `Pillow` | 형식·크기 검사, 투명 PNG 저장 |

라이브러리 추가는 PM1 상준에게 요청합니다.

```
원본 이미지
   ↓ ① 축소          긴 변을 1024px로 줄여 계산 속도 확보
   ↓ ② 배경색 추정    이미지 테두리(가장자리 띠) 픽셀의 대표 색을 배경색으로 봄
   ↓ ③ 1차 마스크     배경색과 색 차이가 작은 픽셀 = "배경일 가능성 높음"
   ↓ ④ GrabCut       1차 마스크를 힌트로 제품/배경 경계를 다시 계산
   ↓ ⑤ 다듬기        작은 구멍 메우기·잡티 제거, 가장 큰 덩어리만 남기기
   ↓ ⑥ 경계 부드럽게  마스크 가장자리를 살짝 흐려 계단 현상 완화
   ↓ ⑦ 원본 크기로 키운 마스크를 알파 채널로 붙여 PNG 저장
결과 PNG (배경 투명)
```

| 단계 | 기법 | 설명 |
| --- | --- | --- |
| ② 배경색 추정 | 테두리 픽셀 중앙값 | 제품 사진은 보통 제품이 가운데, 배경이 가장자리에 있다는 가정 |
| ③ 1차 마스크 | Lab 색공간 색 거리 | RGB보다 사람 눈의 색 차이에 가까워 그림자·조명 변화에 덜 민감 |
| ④ 정교화 | `cv2.grabCut` | 색 분포(GMM)와 그래프 컷으로 전경·배경을 나누는 고전 알고리즘. 학습 데이터 불필요 |
| ⑤ 다듬기 | `morphologyEx`, `connectedComponentsWithStats` | 닫기·열기 연산으로 구멍과 잡티를 정리하고, 가장 큰 영역만 제품으로 선택 |
| ⑥ 경계 처리 | `GaussianBlur` | 마스크 경계를 0~255 사이 값으로 만들어 자연스러운 테두리 |
- 민감도(`color_threshold`, 기본 25)와 커널 크기는 실제 제품 사진으로 조정합니다.
- 전경이 전체의 2% 미만이거나 98% 초과면 처리 실패로 보고 오류를 돌려줍니다.

### 5-4. 한계와 대응

AI 모델보다 가볍고 원리를 설명하기 쉽지만, **배경이 단순할수록 잘 됩니다.**

| 잘 되는 사진 | 어려운 사진 |
| --- | --- |
| 흰색·단색 배경 위 제품 | 배경이 복잡하거나 무늬가 있는 사진 |
| 제품이 가운데, 가장자리에 배경이 보임 | 제품이 사진 가장자리에 닿아 잘린 사진 |
| 제품과 배경 색이 확실히 다름 | 흰 찹쌀떡 + 흰 배경처럼 색이 비슷한 사진 |
- 배경 제거 탭에 "단색 배경에서 찍은 제품 사진일수록 결과가 깔끔합니다."를 표시합니다.
- **민감도 슬라이더**(10~60)를 둡니다(📝). 값을 바꾸면 같은 원본으로 다시 처리합니다. 배경이 남으면 올리고, 제품이 깎이면 내립니다.
- 흰 찹쌀떡 사진은 시연 전에 유색 배경에서 찍은 사진으로 미리 시험합니다.

### 5-5. API (🛠)

**`POST /content_studio/media/api/remove-bg`**

- 요청: `multipart/form-data`, 필드 `image`, 선택 필드 `threshold`(민감도 10~60, 기본 25)
- 민감도만 바꿔 다시 처리할 때는 `image` 대신 처음 응답의 `file_id`와 `threshold`를 보냅니다.
- 사진 편집 창에서 자르거나 돌린 뒤 배경을 지울 때는, 그 결과 이미지를 `image`로 보냅니다.

```json
{ "ok": true, "file_id": "<파일ID>", "result_url": "/content_studio/media/remove-bg/result/<파일ID>.png", "width": 1200, "height": 1200 }
```

```json
{ "ok": false, "error": "15MB 이하의 이미지만 올릴 수 있습니다." }
```

**`GET /content_studio/media/remove-bg/result/<파일ID>.png`**: 결과 PNG를 내려받습니다.

> 지금 API는 `{src}`(이미 올린 사진 주소)를 받아 `{url, note, method}`를 돌려줍니다. 위 형식으로 바꾸면서 사진 편집 창(`sns_image.js`)도 함께 맞춥니다.
> 

### 5-6. 저장과 상태

| 구분 | 위치 |
| --- | --- |
| 원본 | `instance/uploads/content_studio/` |
| 결과 | `instance/exports/content_studio/` (지금은 uploads에 저장 → 옮길 예정) |
- 파일 이름은 사용자가 올린 이름을 쓰지 않고 서버가 만든 ID(`uuid`)로 저장합니다.
- 1차 버전은 DB에 기록하지 않습니다.

| 상태 | 화면 표시 |
| --- | --- |
| 처리 전 | 사진과 "배경 제거" 버튼, 안내 문구 |
| 처리 중 | 로딩 표시, 버튼 누를 수 없음 ✅ |
| 완료 | 체크무늬 위 결과, "배경 제거 이미지 받기" ✅ |
| 형식·용량·크기 오류 | 빨간 안내 문구, 서버로 보내지 않음 |
| 처리 실패 | "배경을 제거하지 못했습니다. 다른 사진으로 다시 시도해 주세요." |
- **범위에서 제외 (추후 검토):** URL로 이미지 불러오기(외부 접속 보안 검토 필요), 여러 장 한 번에 처리, 배경색·배경 이미지 교체, 제품 영역 직접 지정(사각형 → GrabCut 사각형 모드), 지우개·복원 브러시

## 6. 영상 탭 (유진)

| 단계 | 상태 | 내용 |
| --- | --- | --- |
| ① 초안 | ✅ | 요청을 읽어 장면 구성(5초 3컷 / 10초 4컷)과 카메라·조명·분위기·배경을 정리합니다. |
| ② 프롬프트 검토 | ✅ | Higgsfield로 보낼 **영어 프롬프트**를 보여줍니다. 직접 고치거나 "더 밝게 / 카메라 천천히 / 한입 먹는 장면 / 10초로 / 소리 켜줘"처럼 말로 고칩니다. 바뀌면 다시 검토가 필요합니다. |
| ③ 생성 | ✅ | **"이 프롬프트로 영상 만들기"를 눌러야만** 요청합니다. 대기 중 → 만드는 중 → 완료(재생·받기) / 실패 / 거절됨 |
| 규격 | ✅ | 9:16 · 16:9 · 1:1, 5초 · 10초, 소리 켬/끔 |
| 키가 없을 때 | ✅ | "시연" 상태와 안내만 표시하고 요청은 보내지 않습니다. |

Higgsfield 연동은 공식 문서 기준입니다.

- 주소는 `https://api.higgsfield.ai`, 인증 헤더는 `Authorization: Key 아이디:시크릿`입니다.
- 모델은 Kling 2.6 Pro입니다. 사진이 없으면 `text-to-video`, 있으면 `image-to-video`로 요청합니다.
- 요청 후 `/requests/{id}/status`로 상태를 확인하고, 완료되면 `video.url`을 받습니다.
- 첨부 사진은 외부에서 열 수 있는 주소여야 합니다. `PUBLIC_BASE_URL`이 없으면 사진 없이 글 설명만으로 만듭니다.

### 광고 표현 검수·숏폼 콘티 (희주, ✅)

- **광고 표현 검수:** 최상급·효능·할인 등 주의 표현을 표시하고, 이유·바꿔 쓰기·KOTRA 자료 링크를 보여줍니다. **"참고 안내이며 법적 판단이 아님"**을 항상 표시합니다.
- **숏폼 콘티:** 대화에서 "숏폼 콘티 짜줘"라고 하면 장면별 화면과 자막을 만듭니다.

### 문서 형식 (요소 JSON)

```
포스터·카드뉴스 (희주): {kind, template?, ratio, pages: [{layout, bg, accent, elements: [...]}]}
  요소: id, role(title|subtitle|body|badge|brand|image|sticker|shape…), type(text|image|sticker|shape), x, y, w, h, z
    글: text · font(글꼴 key 또는 "local:글꼴이름") · size · weight · color · align · bg
    사진: src · radius
영상 (유진): {kind: "video", ratio, duration, sound, summary, scenes[{time, ko, en}], camera, lighting, mood,
       background, extras[], prompt, custom, image, job{request_id, status, video_url}}
```

이 요소 JSON이 포스터의 **원본 작업 파일**입니다. PNG/JPG/SVG/Figma는 모두 여기서 만듭니다.

### 브랜치와 머지

- 유진·희주는 **각자 개인 브랜치**에서 작업하고 `premain`으로 PR을 올립니다.
- 희주의 PR은 PM2 유진이, 유진의 PR은 PM1 상준이 머지합니다.

### 화면·코드 충돌 방지

- CSS는 `.studio-chat`, `.studio-tabs`, 사진 편집 창은 `.img-editor` 아래에서만 씁니다.
- JS는 ES 모듈입니다. 전역 변수·함수를 만들지 않습니다.
    - `sns.js`가 `sns_editor.js`·`sns_video.js`·`sns_image.js`를 import합니다.
    - `sns_editor.js`가 `sns_fonts.js`를 import합니다.
- 이미지는 `static/images/sns/`에만 넣습니다.

## 11. 완료 기준

**공통**

- [ ]  각자 ✏️ 표시된 파일만 수정했다.
- [ ]  세 탭 모두 첫 화면(내 작업 가로 목록·추천) → 작업 화면 → 이어서 하기가 동작한다.
- [ ]  되돌리기·다시하기가 대화 수정과 직접 수정 모두에 동작한다.
- [ ]  시연 결과와 실제 생성 결과를 화면에서 구분한다.
- [ ]  업로드 사진·생성 결과·API 키가 커밋에 포함되지 않았다.

**포스터**

- [ ]  제목·본문·사진·배경이 독립 요소로 만들어지고, 대화와 직접 수정으로 각각 고칠 수 있다.
- [ ]  PNG/JPG로 받을 수 있고, 작업 원본(요소 JSON)을 다시 열어 고칠 수 있다.
- [ ]  Figma 연동 방식(A/B)의 기술 검증 결과를 기록했다.

**카드뉴스**

- [ ]  받은 템플릿으로 카드뉴스를 만들 수 있다.
- [ ]  기본 프롬프트가 모든 생성 요청에 들어간다.

**배경 제거**

- [ ]  JPEG·PNG·WEBP 각각 배경이 지워지고 투명 PNG로 받아진다.
- [ ]  15MB 초과, 4096px 초과, 지원하지 않는 형식이 화면과 서버 양쪽에서 막힌다.
- [ ]  흰 배경·유색 배경 제품 사진에서 제품 테두리가 깔끔하게 남는다.
- [ ]  민감도를 바꾸면 같은 원본으로 다시 처리된다.
- [ ]  4096px 이미지도 5초 안에 처리된다.
- [ ]  처리 중에는 버튼을 다시 누를 수 없고, 실패해도 화면이 멈추지 않고 안내 문구가 나온다.

**영상**

- [ ]  사용자가 프롬프트를 승인하기 전에는 생성 요청을 보내지 않는다.

**검수**

- [ ]  광고 표현 검수에 "참고 안내이며 법적 판단이 아님"이 표시된다.
