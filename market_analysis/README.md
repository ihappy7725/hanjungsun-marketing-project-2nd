# 현지 시장 분석 (market_analysis) 기능 설계안

> 담당: 상준 (PM1) · 폴더: `market_analysis/` · URL: `/market_analysis/`
> 문서 상태: **초안 (2026-10-23)**. 화면 시안은 더미 데이터로 만든 대시보드를 기준으로 합니다.

---

## 1. 개요

### 목적
한정선 찹쌀떡의 현지 진출을 맡은 글로벌 마케터가 아래 세 가지를 한 화면에서 판단하도록 돕습니다.
- **무엇을** 팔지
- **언제, 어디서** 팔지
- **어떻게** 알릴지

### 기본 방향
- **국가 선택형 구조**: 베트남이 기본값입니다. 국가 코드만 바꾸면 같은 화면 틀이 다른 나라(태국, 인도네시아, 필리핀, 말레이시아, 일본, 미국)에도 그대로 적용됩니다.
- **우선 진출 도시: 베트남 다낭**
- **데이터 원칙**
  - 실제로 가져올 수 있는 데이터만 화면에 넣습니다.
  - 시연 데이터와 실제 데이터를 화면에서 구분합니다.
  - 모든 카드에 출처와 기준일을 표시합니다.
  - 모든 카드에 **지역 범위(다낭 / 베트남 전국)**를 표시합니다. 전국 자료를 다낭 전용 데이터처럼 설명하지 않습니다 (전체 README 9장 공통 기준).
- **디자인**: 화면 시안의 색은 임시입니다. 구현할 때는 전체 README 6장의 디자인 변수(`base.css`), 패널 제목(영문 소제목 + 한국어 제목), `DEMO · 예시 데이터` 표시, 선 아이콘 규칙을 따릅니다. 차트 라이브러리는 팀 확정안(Chart.js / Plotly 중 하나)을 씁니다.

### 탭 구성 (4개)
| 순서 | 탭 | 역할 |
|---|---|---|
| 1 | 트렌드 분석 | 현지 검색 관심도로 시장 흐름 · 시기 · 지역 파악 |
| 2 | 경쟁제품 분석 | 경쟁 제품의 가격 · 구성 · 판매량 · 마케팅 기법 파악 |
| 3 | 국가 · 문화 | 금기 · 상징 · 패키징 · 기후 등 현지화 기준 |
| 4 | AI 인사이트 | 1~3번 데이터를 모아 한정선 전용 전략 도출 |

## 2. 공통: 국가 선택 바
- 국가 칩: 베트남(기본) · 태국 · 인도네시아 · 필리핀 · 말레이시아 · 일본 · 미국 + "국가 추가"
- 표시 정보: 언어 · 통화, 수집한 경쟁 제품 수, 핵심 경쟁사 수
- URL 형식: `/market_analysis/?country=VN&tab=trend`
- 국가 정보는 `countries.py` 등록부 한 곳에서 관리합니다. 국가 추가 = 등록부에 한 줄 추가.

## 3. 트렌드 분석

### 데이터 출처
- **Google Trends** 하나만 씁니다.
- 공식 Trends API(알파)는 아직 일부 테스터에게만 열려 있습니다. 그 전까지는 Google Trends 화면의 CSV 내보내기로 받아 저장합니다.

### 필터
- 기간: 7일 / 30일 / 90일
- 카테고리 6개

| 카테고리 | 판단에 쓰는 곳 | 조회 검색어 (베트남 예시) |
|---|---|---|
| 떡·모찌 | 직접 경쟁 시장이 커지는지 | bánh mochi |
| 현지 쌀 디저트 | 쫀득한 쌀 식감이 통하는지 · 대체재 | bánh nếp |
| K-푸드 | "한국산"이 강점이 되는지 | đồ ăn Hàn Quốc |
| 과일 디저트 | 어떤 현지 과일 맛이 뜨는지 | bánh + 과일명 |
| 선물·명절 | 선물 시즌 · 구성 판단 | hộp quà tết |
| 건강·저당 | "쌀로 만든 담백한 간식" 메시지 적합성 | đồ ăn vặt ít đường |

### 카드 구성 (6개)
| # | 카드 | 보여주는 것 | 데이터 |
|---|---|---|---|
| 1 | 핵심 요약 3칸 | 떡·모찌 관심도 변화 · 급상승 1위 검색어 · 과일 한정판 1순위 | 아래 카드 값으로 계산 *(화면 유지 여부 검토 중. 같은 값을 HOME H06용 `get_trend_summary()`로 제공하는 안 — 8장)* |
| 2 | 급상승 검색 키워드 | 기준 검색어와 함께 급상승한 검색어 순위 | Trends 관련 검색어(급상승) |
| 3 | 카테고리 관심도 추이 | 카테고리별 자기 기준 변화율 + 추이선 | Trends 시간별 관심도 |
| 4 | 현지 과일 맛 트렌드 | 과일 5종 관심도 순위 + 제철 상태 + 한정판 1순위 | Trends (5개 동시 비교) + 제철 고정 데이터 |
| 5 | 월별 검색 계절성 | 5년 월평균 관심도 막대 · 피크 달 · 준비 시점 | Trends 5년 월별 (다낭 지역 기준. 다낭 데이터가 부족하면 전국 값으로 바꾸고 "전국 기준"으로 표시) |
| 6 | 베트남 지역별 관심도 | 성(省) · 도시별 관심도 순위, 다낭 강조 | Trends 지역별 관심도 |

### 카드별 세부
- **현지 과일 맛 트렌드**
  - 대상 과일 5종(베트남): 망고 · 리치 · 두리안 · 용과 · 코코넛
  - 과일 이름을 누르면 계절성 카드가 그 과일로 바뀝니다.
- **월별 검색 계절성**: 마케터 업무 기준 4개 분류로 봅니다.

  | 분류 | 보는 것 | 알려주는 행동 |
  |---|---|---|
  | 명절 선물 시즌 | 뗏 · 중추절 선물 검색 | 선물세트 발주 · 사전 예약 판매 시점 |
  | 기념일 선물 시즌 | 여성의 날(3/8 · 10/20) · 스승의 날 선물 검색 | 기념일 2~3주 전 SNS · 인플루언서 캠페인 |
  | (과일) 한정판 시기 | 선택한 과일 디저트 검색 | 한정판 맛 출시 시기 |
  | 다낭 관광 성수기 | 다낭 여행 검색 | 공항 · 관광지 기념품 채널 물량 확대 |

- **지역별 관심도**
  - "무엇에 대한 관심?" 버튼으로 주제를 고릅니다: 찹쌀떡·모찌 / 한국 디저트 / 디저트 선물
  - 값은 "지역 전체 검색 중 이 주제의 비율"입니다. 인구가 많다고 높게 나오지 않습니다. 가장 높은 지역이 100입니다.
  - 다낭 순위 · 관심도와 해석, 유통 · 배송 확인 사항을 함께 보여줍니다.

### 구현 규칙
1. 표현은 "검색량"이 아니라 **"관심도(0~100)"**로 합니다. Trends는 상대 지수를 줍니다.
2. 서로 크기를 비교하는 카드는 **검색어 5개 이하**로 맞춥니다. Trends의 한 번 비교 한도입니다.
3. 조회는 **현지어 검색어**로 합니다. 국가별 대응표는 `countries.py`에 둡니다. 실제로 조회해 값이 0이 아닌지 확인한 뒤 확정합니다.
4. 월 1회 수집해서 `market_analysis_` 테이블에 저장합니다.

### 제외한 항목
- 뉴스 헤드라인: HOME 뉴스 위젯으로 이동. 원본은 `get_news_summary()`로 제공합니다. 뉴스 API는 Google 뉴스 RSS(베트남어)를 검토합니다. NewsAPI는 베트남어를 지원하지 않습니다.
- 마켓셰어, SNS 해시태그 언급량, 실제 검색 횟수: 데이터를 구할 수 없거나 유료 · 광고 계정이 필요해서 뺐습니다.

## 4. 경쟁제품 분석

### 화면 구성
1. **요약 3칸**: 수집한 경쟁 제품 수(기준일) · 핵심 경쟁사 ★ 수 · 평균 개당 가격
2. **세그먼트 필터**: 버튼마다 제품 수 · 개당 평균 가격 표시
   - 현지 전통 떡 / 일본식 모찌 / 모찌 아이스크림 / 한국 떡 / 떡 선물세트
3. **경쟁 제품 목록**: 검색 · 원산지 필터 · ★ 핵심만 보기 · 정렬(판매량 / 개당 가격) · 8개씩 페이지

   | 열 | 내용 |
   |---|---|
   | 핵심 | 별표(선 아이콘)로 핵심 경쟁사 지정 (AI 인사이트에 사용) |
   | 브랜드 · 제품 | 누르면 상세 열림 |
   | 세그먼트 | 위 5개 중 하나 |
   | 원산지 | 현지 / 한국 / 일본 / 태국 등 |
   | 구성 | 입수 · 개당 중량 |
   | 판매가 | 상품 페이지 가격 |
   | 개당 가격 | 판매가 ÷ 입수 |
   | 월 판매량 | 누적 판매 수의 월별 차이로 추정 |

4. **제품 상세**
   - 기본 정보 6개: 세그먼트 · 원산지 · 구성 · 판매가 · 개당 가격 · 월 판매량(추정)
   - 이 경쟁사가 쓰는 마케팅 기법 6종:

     | 기법 | 예시 | 출처 |
     |---|---|---|
     | 프로모션 · 가격 | 1+1, 라이브커머스 번들 할인 | 상품 페이지 |
     | SNS · 인플루언서 | 숏폼 챌린지, 언박싱 영상 | 브랜드 SNS |
     | 시즌 · 한정 전략 | 계절 한정 맛, 명절 한정 판매 | 상품 페이지 · SNS |
     | 패키징 · 디자인 | 빨강 · 금색 고급 상자, 개별 포장 | 상품 이미지 |
     | 핵심 메시지 | "일본 정통 다이후쿠" | 상품 설명 |
     | 판매 이벤트 | Shopee 라이브, 매장 시식 | 상품 페이지 · 라이브 |

   - 월별 판매 추이(추정), 입점 채널 목록, 소비자 반응(리뷰 키워드)
   - 한정선이 참고할 점 (한 줄)
   - 한정선 가정 가격과 개당 가격 비교

### 경쟁사 수집 기준
- **포함**
  - 찹쌀 · 쌀가루로 만든 쫀득한 디저트 (찹쌀떡, 다이후쿠, 모찌, 모찌 아이스크림, 현지 찹쌀 떡)
  - 대상 국가에서 현재 판매 중이고, 최근 3개월 안에 판매 기록이 있는 제품
- **제외**: 카페 즉석 디저트, 수제 소량 판매, 떡볶이 등 비디저트 떡
- **핵심 경쟁사(★) 기준**: 아래 5개 중 3개 이상에 해당하는 제품
  1. 같은 제품 형태 (직접 대체재)
  2. 한정선 가정 가격 ±30%
  3. 같은 입점 채널
  4. 같은 타깃
  5. 세그먼트 판매 상위 3위

### 수집 방법
- **이커머스(주 출처)**: Shopee · Lazada · TikTok Shop에서 현지어 키워드로 검색해 판매량순 상위 20~30개를 월 1회 수동 조사합니다. CSV로 업로드합니다.
- **오프라인**: 편의점 · 마트 · 한인 마트의 입점 여부와 매대 가격을 매장 조사로 확인합니다. 판매량은 알 수 없습니다.
- **브랜드 SNS**: 마케팅 기법 · 캠페인 사례를 기록합니다.
- **보완 자료**: KOTRA 해외시장뉴스, aT KATI
- **지역 범위**: 이커머스 가격 · 판매량은 베트남 전국 기준입니다. 다낭 매장 조사 값은 "다낭"으로 따로 표시합니다.
- **주의**
  - 쇼핑몰 자동 수집(크롤링)은 이용약관 제한이 있습니다.
  - 판매자 공식 API는 내 가게 데이터만 볼 수 있습니다.

### 제외한 항목
- 세그먼트별 매출 비중 %, "가장 큰 판매 채널", 채널별 판매 비중 %: 오프라인 판매량을 구할 수 없어서 뺐습니다.
- 가격 포지셔닝, 보관 방식별 유통 비교, 보관 방식 필터: 역할이 겹치거나 범위 밖이라 뺐습니다.

| 기후 · 유통 환경 | 남부 고온다습 · 우기, 북부 결로(nồm), 오토바이 배송 고온 노출 |

- 문화 정보는 출처와 검토일을 함께 기록합니다. 시연 내용은 발표 전 KOTRA 등 자료로 검증이 필요합니다.

## 6. AI 인사이트

### 입력 항목: **미정**
현재 시안에 넣어 둔 항목은 참고용입니다. 팀 논의 후 확정합니다.
- (시안) 필수: 마케팅 목표 · 출시 희망 시기 · 예산 규모 · 과일 맛 생산 가능 여부 · (인도네시아 · 말레이시아) 할랄 대응
- (시안) 자동 채움: 가정 개당 가격 · 보관 방식 · 핵심 경쟁사 ★

### 출력 구성 (시안)
1. 사용한 데이터 요약 + 입력 조건 한 줄
2. 실행 우선순위 Top 3: 목표에 따라 순서가 바뀌고, 담당 탭 링크가 붙습니다
3. SWOT 자동 분석: 항목마다 근거 데이터 태그
4. 현지화 가이드: 맛 · 포장 · 구성 · 가격
5. 시즌별 현지 과일 맛 로드맵: 제철 × 기념일은 규칙으로 계산하고, AI는 이유만 설명합니다
6. 마케팅 정책 제안: 채널 · 프로모션 · 인플루언서 · 시즌 캠페인
7. 추천 타깃 페르소나 3개
8. 신뢰도 · 검토 필요 안내

### 원칙
- AI가 일반론을 지어내지 않도록, 서버(`routes.py`)에서 대시보드 데이터를 모아 AI에 같이 넘깁니다. 결과는 정해진 JSON 형식으로 받습니다.
- 모든 제안에 근거 데이터를 표시합니다. 화면에는 "AI 제안 · 검토 필요"를 붙입니다.
- AI 키는 서버에서만 사용합니다.
- 조건이 바뀌면 "다시 생성" 안내를 띄웁니다.
- 역할 경계: 상준 = 전략(무엇을 · 언제 · 왜), 콘텐츠 스튜디오 = 실제 제작 (희주: 포스터 · 카드뉴스 · 문구, 유진: 영상)
- AI 제공사와 키 이름은 팀 확정 전까지 미정입니다 (전체 README 8장 "AI 제공사" 합의 항목). 키 이름이 정해지면 PM1이 `.env.example`에 추가합니다.
- 다른 탭으로 가는 링크(HOME 역산 캠페인 · 콘텐츠 스튜디오 · 인플루언서 · KPI) 주소 형식은 전체 README 8장 "탭 간 링크 주소 형식" 합의를 따릅니다.

## 8. 다른 탭과의 연결 (`public.py`)

| 함수 | 반환 (안) | 사용하는 탭 |
|---|---|---|
| `get_events(country="VN", year=None)` | `event_id, country, name, date, type(holiday / anniversary / fruit_season)` + 추가 검토: `end_date, region, source, is_demo` | HOME 캘린더 · 캠페인, 콘텐츠 스튜디오, 인플루언서 마케팅 |
| `get_news_summary(country="VN", limit=5)` | `news_id, country, title, summary, source, published_at` + 추가 검토: `link, region` | HOME 뉴스 위젯 (H06) |
| `get_trend_summary(country="VN")` *(신규 제안)* | `item, value, sub, source, as_of, region, is_demo` (트렌드 탭 핵심 요약 3칸과 같은 값) | HOME 트렌드 요약 (H06) |

- `event_id` 형식(안): `{국가코드}_{이름}_{연도}` (예: `vn_teachers_day_2026`)
- 과일 시즌은 하루가 아니라 기간이라서, `type=fruit_season`이면 `date`를 시작일로 쓰고 `end_date`를 함께 주는 안을 제안합니다 (전체 README 8장 합의 항목).
- 데이터가 없으면 빈 리스트를 반환합니다. 껍데기 `public.py`를 가장 먼저 머지합니다.
